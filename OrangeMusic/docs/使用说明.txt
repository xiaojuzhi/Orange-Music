Orange Music 本地音乐播放器
============================

启动方法：
双击“Orange Music.lnk”，或进入 Orange Music 文件夹运行 Orange Music.exe。

注意事项：
1. 这是免安装便携版。
2. Orange Music.exe 必须和整个 Orange Music 文件夹一起使用，不要单独移动 EXE。
3. 音乐扫描、歌词和播放操作均在本机完成。
4. 支持 MP3、AAC、FLAC、ALAC、WAV、M4A 等常见音频格式。
5. 扫描导入已放在“扫描导入”二级页面，不在首页。

常用快捷键（可在“设置 → 快捷键”中关闭）：
空格            播放 / 暂停
← / →           快退 / 快进 5 秒
↑ / ↓           音量减小 / 增大
Ctrl + ← / →    上一首 / 下一首
M              静音
F              收藏当前歌曲
L              打开 / 关闭歌词界面
Q              播放队列
S              随机播放
R              切换循环模式
Ctrl + K       搜索
Esc            关闭弹层 / 返回

窗口操作：
- 按住窗口顶部标题栏拖动可以移动窗口（歌词界面顶部同样可以拖动）。
- 双击标题栏可以在“全屏（最大化）”和“小窗”之间切换，主界面和歌词界面都支持。

支持的音乐格式：
- 直接播放：MP3、FLAC、AAC / M4A、WAV、OGG、Opus。
- 自动转换播放：ALAC、AIFF、WMA、APE（软件内置 FFmpeg，会在本机转码后播放，不联网）。
- 软件已不再内置示例歌曲，第一次使用请先导入自己的音乐。

关于歌曲资料库：
- 导入过的歌曲会记在资料库里，下次打开软件会自动恢复（前提是原文件还在原位置）。
- 收藏、最近播放、播放队列在重启后同样会保留。
- 如果歌曲文件被移动或删除，重新扫描导入一次即可。

关于歌词：
- 会自动读取同名歌词文件（歌曲.mp3 旁边的 歌曲.lrc），支持 UTF-8 / UTF-16 / GBK 编码。
- 也会读取内嵌歌词：MP3 的 USLT / SYLT / TXXX 歌词帧、FLAC 的 LYRICS 标签、M4A 的 ©lyr。
- 如果都没有，可以在歌词界面用「导入」选择 lrc 文件，或「粘贴」歌词文本。

设置页可以调整：
- 播放：淡入淡出、记忆播放进度、播完自动下一首、显示音频波形。
- 播放浮窗：背景效果（模糊 / 亚克力 / 半透明 / 高斯模糊）、模糊程度、透明程度。
- 歌词界面：歌词字号、封面模糊背景。
- 主题颜色：默认白 / 蜜桃 / 薄荷 / 天青 / 藕荷 / 柠檬 / 樱花 等浅色调，一键切换整界面配色。
- 左侧功能栏：背景效果（模糊 / 亚克力 / 半透明 / 高斯模糊）、模糊程度、透明程度。
- 启动与导入：启动恢复上次歌曲、导入后自动播放。

关于歌曲信息识别：
- MP3：读取 ID3 标签（标题 / 歌手 / 专辑 / 封面 / 内嵌歌词）。
- FLAC / OGG / Opus：读取 Vorbis 注释（标题 / 歌手 / 专辑 / 歌词 / 封面）。
- M4A / MP4：读取 iTunes 标签（标题 / 歌手 / 专辑 / 歌词 / 封面）。
- WAV：读取 RIFF INFO 标签；没有标签时按“歌手-歌名”从文件名推断。
- 网易云 .ncm、QQ音乐 .qmc/.mflac、酷狗 .kgm 等加密文件无法播放，导入时会给出提示，请使用普通 MP3 / FLAC 文件。
关于扫描导入的过滤：
- 「只导入歌曲」默认开启：扫描文件夹时会自动跳过音效、提示音、语音、错误音等非歌曲音频。
- 判断依据：标签（标题+歌手）、音频时长、文件名与所在目录（如 sfx / sounds / voice / ui / click / 提示音 / 音效 等）。
- 「歌曲最短时长」默认 30 秒：没有标签又短于该时长的音频会被当成音效跳过；有标题+歌手的正常歌曲不受影响。
- 扫描结束后状态栏和提示会写明「新增 X 首歌曲，跳过 Y 个非歌曲音频」，被跳过的文件名也会列出来。
- 想连音效一起导入时，可在「设置 → 启动与导入」里关掉「只导入歌曲」。
关于删除歌曲：
- 在「歌曲」或「喜爱」列表里把鼠标移到某一行，右侧会出现垃圾桶按钮，点一下确认即可把这首歌从资料库移除。
- 播放队列里的每一行也有同样的删除按钮。
- 「歌曲」页面右上角有「清空资料库」，可以一次性移除全部记录。
- 以上操作只删除软件里的记录，不会删除你磁盘上的音乐文件；被移除歌曲的收藏、最近播放、歌单记录也会一起清理。
新增功能一览（设置页里都能找到）：
- 歌词：歌词时间微调（±2 秒，解决对不上）、非当前行模糊、歌词界面配色（跟随封面 / 深色 / 浅色）。
- 播放：播放速度 0.5×–2×、淡入淡出时长、睡眠定时器（15/30/45/60/90 分钟或播完本曲）、音量均衡（ReplayGain）。
- 均衡器：五段（60Hz / 230Hz / 910Hz / 3.6kHz / 14kHz），带流行、摇滚、古典、人声、低音/高音增强等预设。
- 音乐库：每首歌可查看详情（格式、时长、大小、码率、采样率、声道、位深、文件位置）、可编辑标题/歌手/专辑/封面（只改资料库，不动原文件）、可移除单曲或清空资料库、「查找重复」一键清理重复歌曲。
- 歌单：重命名、换封面、导出 m3u、导入 m3u。
- 自动扫描：添加常用音乐文件夹，开启后启动时自动扫描，只把新歌加进来；配合「只导入歌曲」自动跳过音效。
- 快捷键：在设置里点任意一行即可按下新按键改键，「恢复默认」可重置。
- 界面：列表密度（宽松 / 紧凑）。
- 系统：最小化到托盘、关闭时最小化到托盘（后台继续播放）、开机自动启动；托盘图标右键可播放/暂停、上一首/下一首。

说明：本软件是 Windows 桌面程序（PC 端），没有网页版；直接双击 Orange Music.exe 使用即可。
关于歌词读取：
- 每次播放、打开歌词界面或点「重新读取」时，都会重新从文件里找歌词：先读歌曲内嵌歌词，再找同目录的同名 .lrc。
- 内嵌歌词支持：MP3 的 USLT / SYLT / TXXX（LYRICS、UNSYNCEDLYRICS、LRC、歌词等写法），FLAC / OGG 的 LYRICS、UNSYNCEDLYRICS，M4A / MP4 的 ©lyr；标签写在文件开头或结尾都能识别。
- 同名歌词文件支持 UTF-8 / UTF-16 / GBK 编码，文件名可带 01. 之类的前缀。
- 歌词标题旁边会标明来源（歌曲内嵌 / 同名歌词文件 / 手动导入）；找不到时可点「重新读取」或手动导入。
歌词格式兼容说明：
- 标准 LRC：[00:12.34]歌词
- 同一句多时间标签（副歌重复）：[00:10.00][01:20.00]副歌 —— 会在两个时间点各显示一次
- 逐字卡拉OK格式：[00:00.000]反[00:00.254]方[00:00.508]向 —— 会合并成整句显示，不再重复
- 增强型尖括号标签：<00:05.00>你<00:05.20>好 —— 时间标签会被去掉，只留文字
- 带 [offset:500] 的歌词会自动按偏移校准
- 连续重复的同一句会自动合并
界面与歌词体验（本次更新）：
- 歌词界面顶部不再显示「歌词 / 重新读取 / 导入 / 粘贴」按钮，歌词区域保持干净；这些功能收进了「歌曲信息」弹窗（列表里的 ⓘ 按钮）。
- 歌词支持逐字点亮：歌里有逐字时间轴时精确同步，没有时按整句时长均分；已点亮的字有轻微漂浮动画，当前句字号平滑放大。
- 播放中手动上下滚动歌词不会被打断，9 秒后自动恢复跟随，也可以点右下角「回到当前」立即回到当前句。
- 歌词界面「喜欢」旁边的 ⋯ 按钮现在会弹出「添加到歌单」。
- 全局动效统一为更线性的缓动曲线，页面切换、弹窗、抽屉、卡片悬停都更平滑。
- 主界面底部播放浮窗改为居中、更短（最大 1120px、高 68px），悬浮感更强、不遮挡内容。
- 配色整体微调：更中性的灰白背景、更克制的边框与阴影，强调色统一为品牌红（#FA2D48）。

歌词时间微调（右键菜单）：
- 在歌词界面任意位置点右键，会弹出「歌词时间微调」菜单。
- 「歌词提前 0.25 秒」/「歌词延后 0.25 秒」：每点一次调整 0.25 秒，可以连续点。
- 调整只对当前这首歌生效，会自动记住，下次播放同一首仍然有效（存在资料库里）。
- 「重置这首歌的微调」：把这首歌的偏移清掉。
- 「把当前值应用到所有歌曲」：把当前偏移设为全局默认值，清除各歌曲的单独设置。
- 设置页里的「歌词时间微调」滑杆调的是全局默认值；拖动它会清除当前歌曲的单独微调。
