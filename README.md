# Orange Music · 本地音乐播放器

[![version](https://img.shields.io/badge/version-1.8.0-orange)](https://github.com/xiaojuzhi/Orange-Music/releases)
[![license](https://img.shields.io/badge/license-MIT-blue)](LICENSE)
[![platform](https://img.shields.io/badge/platform-Windows%2010%20%2F%2011-lightgrey)](https://github.com/xiaojuzhi/Orange-Music)

一个 Windows 桌面音乐播放器：本地曲库支持 MP3 / FLAC / AAC / WAV / OGG 等常见格式，自动读取标签与封面；同时内置在线音乐页，登录网易云 / QQ 音乐 / 酷狗后可以直接在播放器里在线播放，歌词自动匹配。歌词逐字同步，内置十段均衡器与音量均衡，支持多歌单与资料库自动扫描，还带托盘控制、全局快捷键和可自定义的界面配色。  
用 Electron + 原生 HTML / CSS / JavaScript 写成，没有前端框架依赖。

## 更新日志

### v1.8.0

- **封面 / 歌名也能进歌词页**：播放条左侧那块原来是死的，只能点右边的歌词按钮。现在封面 + 歌名 + 歌手整块包成一个按钮，点一下直接进全屏歌词，鼠标移上去封面轻微放大、投一层浅影，键盘 Tab 也能选中回车进入
- **播放条的「全屏」名副其实了**：那颗按钮以前其实只是把歌词页铺满窗口，窗口照样带着标题栏和任务栏，跟旁边写着「全屏」的图标对不上。现在点它是真·窗口全屏（和 F11 同一条路径），主界面也能全屏看列表；再点一次或按 Esc / F11 退回窗口，图标同步换成「向内四角」
- **歌词页右上角补回窗口三键**：歌词页是 `fixed; inset: 0` 的全覆盖层，把自绘标题栏整块压在下面，最小化 / 最大化 / 关闭直接就没了，想关窗只能退回主界面。现在歌词页自带一套——顺序跟真窗口一致，全屏在最左，右边依次是 —、□、✕；四颗统一 36×36 圆形、间距 2px、1.7 笔画（全屏 15px，其余 14px，视觉上一般大），悬停浮出淡色圆底、关闭键是极淡红晕，最大化后 □ 自动变「还原」。顺带把原来那颗 46×52、图标只有 9.5px 可见的「第四个 caption 按钮」重做成同样规格，深色歌词用白、浅色歌词自动转黑
- **系统媒体面板终于有封面了**：`MediaImage` 只认 http/https/data/blob，本地封面是 `file://`，Chromium 直接拒收（控制台常驻一条警告）；而页面里把 `file://` 图画到 canvas 再 `toDataURL` 会被判跨源、抛 SecurityError 被静默吞掉。于是锁屏、音量弹窗、耳机线控面板里一直是空白。现在封面交给主进程用 `nativeImage` 读取、居中裁方、压到 256×256 再以 data URL 下发，整条链路一次通
- **播放失败不再无声无息**：文件被移走、磁盘上被删、格式不被支持时，`<audio>` 只会默默扔一个 error 事件，以前没人接——用户看到的就是「点了播放，进度条不动、没声音、也不提示」。现在会明确提示是哪首歌失败，连播时自动跳过；连跳 3 首就停手并说明原因，避免整个文件夹被移走时一首首刷屏
- **页面加上 CSP**：主窗口之前完全没有内容安全策略，Electron 启动就报一条安全警告。现在按 `file://` 加载的实际需要显式放行同目录脚本 / 样式 / 媒体，`img` 与 `media` 允许 http(s)（在线封面、在线音频），`object-src 'none'`、`base-uri 'self'`，没有任何 inline 脚本
- **桌面歌词按钮会亮了**：以前开与关都没有任何视觉反馈，按钮永远灰着，用户不知道那块置顶浮窗到底开没开。现在开着时按钮变主色 + 淡底，提示文字也换成「关闭桌面歌词」，从浮窗那边点 ✕ 关掉后主界面同步熄灭
- 修掉一处版本号漂移：LRCLIB 请求头里写死的 `OrangeMusic/1.7.2` 改成读 `app.getVersion()`，以后升版本不会再说错
- 清理 7 个再也没被引用的图标定义和 1 个未使用变量（`lastDesktopLyricsPush`）

### v1.7.1

- **耳机校正（AutoEq）**：均衡器里新增「耳机校正」，收录 AutoEq 全量结果 —— **2316 款耳机**（724 款头戴 + 1592 款入耳，228 个品牌），带搜索框，输 `hd650`、`airpods pro`、`1000xm5` 都能直接命中（忽略空格、连字符、大小写）。选中后直接把 AutoEq 的 `FixedBandEQ` 曲线写进现有十段增益 —— 频点 31Hz–16kHz 与播放器的 `EQ_BANDS` 完全一致，不需要改音频链，只多接了一个预增益节点。曲线自带的 Preamp 会同步生效，避免校正后低频抬升处削波。校正状态下十段滤波器切成 AutoEq 计算所用的 `PK` / `Q=1.41`（默认预设仍是原来的 shelving），结果与原版一致。选完还能继续拖滑块微调，按钮下方会标注「已在曲线上手动微调」；切回内置预设时校正自动撤销。列表分批渲染，首屏头戴 / 入耳各 60 条，滚到底自动续，两千多条也不卡
- **Windows 系统媒体控制（SMTC）**：接入 `navigator.mediaSession`，锁屏界面、音量弹窗、耳机线控和键盘媒体键现在都能看到封面、歌名、歌手与进度条，并可直接控制播放 / 暂停 / 上一首 / 下一首 / 快进快退。此前系统里只有一条 `index.html` 的空记录（没有封面、没有歌手，窗口失焦时按键也没反应）。封面会转成 256×256 的 data URL 随元数据下发，不依赖系统去读本地路径；媒体键与 SMTC 回调可能同时到达，切歌做了 350ms 去重，一次按键只跳一首
- 均衡器滑杆步进从 1dB 改成 **0.5dB**，校正曲线取整后滑块位置和实际增益一致（不会出现「显示 +3、实际 +2.6」）
- **专辑 / 艺术家视图**：资料库页顶部多了「歌单 / 专辑 / 艺术家」切换。以前整个曲库只有一张平铺的歌曲表，几千首歌想「听整张专辑」只能靠搜。现在按标签自动分组：专辑按「专辑名 + 歌手」区分（同名专辑不同歌手是两张），曲目按文件名 / 标题开头的序号排；艺术家页显示每人名下的专辑数与曲目数。点卡片进详情页，版式与歌单详情一致，「播放全部 / 随机播放」直接把这一组灌进播放队列；专辑详情里把重复的「专辑」列收掉了
- **在线补词（LRCLIB）**：本地歌既没有内嵌歌词、同目录也没有同名 `.lrc` 时，按歌名 + 歌手 + 时长去 LRCLIB（300 万首，免费无 key）查一次，命中就用它的同步歌词。请求在主进程发，绕开页面 CSP，6 秒超时；候选里按「歌名 / 歌手是否完全一致 + 时长差是否在 3 秒内」打分，避免同名翻唱、现场版拿错词。每首歌只查一次，可以在设置 → 歌词界面里关掉
- **音频输出设备**：设置 → 播放里可以选择声音从哪块声卡 / 耳机出来，默认「跟随系统默认」会随 Windows 切换设备自动跟过去。音频是从 `AudioContext` 出去的，所以切的是 `audioContext.setSinkId`（只改 `<audio>` 不会有任何变化）；插拔耳机后设备列表会自动刷新，选中的设备消失时回落到系统默认并提示
- **均衡器「我的预设」**：原来只能存一套匿名的「自定义」，现在可以命名保存多套（同名覆盖），下拉里单独分组；支持导出 `.json`（带频率标注与预增益）、导入 `.json`，也能直接吃 EqualizerAPO 的 `Filter: ON PK Fc 105 Hz Gain 4.5 dB` 和 `GraphicEQ:` 参数 —— 按对数频率映射到十段，多个滤波器落在同一段时取平均，不会叠成 +30dB
- **单实例**：加了 `requestSingleInstanceLock`，第二次双击（或双击关联文件）不再开第二个进程，而是把已有窗口还原并置前。以前两个实例会同时播放、同时写同一份配置，退出时后写的那份覆盖前一份，表现就是「改过的设置自己变回去了」
- **迷你播放器小窗**：播放条右侧新增小窗按钮，打开后是一个 360×116 的置顶悬浮窗（透明无边框，实际窗口 384×140，四周留出投影空间）。玻璃质感：暖白半透明 + 内高光边 + 暖色投影，封面 72px、歌名 + 艺人、当前歌词行、可拖动的细进度条，右侧上一首 / 播放 / 下一首。整窗可拖动，位置记在 userData，下次打开回到原处；双击空白处或点右上角箭头回主窗口，悬停才显示关闭按钮。主窗口每 200ms 推一次状态（歌名、歌词、进度、播放态），小窗上的操作回传给主窗口执行，关掉主窗口时小窗一并退出
- **自绘窗口按钮**：右上角最小化 / 最大化 / 关闭改成自绘。系统标题栏 overlay 的关闭键悬停时是整块鲜红且改不了色，现在三颗都是 14px 细线图标，悬停走柔和灰底，关闭键只给极淡红晕；最大化后图标自动换成「还原」，双击标题栏空白处也能最大化 / 还原。窗口改为 `frame:false`，代价是最大化按钮上的 Win11 贴靠布局菜单不再出现（拖到屏幕边缘分屏仍然可用）

### v1.7.0

- **人声消除（伴奏模式）**：全屏歌词页「喜爱」左边多了一个话筒开关。打开后把立体声拆成左右两路做相位相减（L−R），人声、贝斯、底鼓这些摆在正中的信号会被抵消，只剩左右不同的乐器，适合跟着唱。150Hz 以下的低频单独补回来，避免一开就变得像手机外放。干湿切换用 20ms 斜坡，不会爆音；单声道音源（L 和 R 完全相同）开启前会检测并拦下，切歌时也会自动关掉，不会莫名静音。状态跟随偏好持久化
- **任务栏显示应用名**：窗口标题之前被主动清空（为了不让页面 title 顶掉自绘标题栏），连带 Windows 任务栏气泡、Alt+Tab 列表里也只剩一个图标没有名字。现在标题固定为 `Orange Music`，页面 title 变化不再影响窗口标题
- **音质提示显示实听参数**：切音质后的提示从营销档位名（「超清母带」）改成真实参数，形如 `音质已切换为 FLAC · 24bit · 96kHz`。主进程在解析直链时顺带用 Range 请求读前 96KB 文件头（FLAC STREAMINFO / MP3 帧头 / MP4 mdhd / WAV fmt），同一档位给到的文件是 16bit/44.1k 还是 24bit/96k 一眼可见；探测失败时自动退回档位名，不影响播放
- **窗口全屏**：新增真正的窗口全屏（`F11`），和以前那个「全屏歌词页」是两回事 —— 后者只是把歌词铺满窗口，标题栏和任务栏还在。播放页右上角加了一颗全屏按钮，全屏后主界面不保留任何悬浮按钮，退回靠 `F11` / `Esc` / 双击顶部边框。全屏状态由主进程事件推送，避免 Windows 上回查 `isFullScreen()` 读到过期值把刚生效的样式抹掉
- **首页每日推荐**：首页主卡片和「推荐播放」区块现在优先展示当前账号的每日推荐，点「查看全部」进每日推荐列表、支持整张歌单连播。没网 / 没登录 / 拉取失败时自动回落到本地曲库推荐，并把标题、右上按钮文案、「全部 N 首」等被在线模块改过的元素还原干净，不会出现「标题写着今日推荐、内容却是本地歌」
- **设置页改成左侧导航分栏**：原来一条长列表往下滚，找某一项得一直滑。现在左侧按「播放与音效 / 外观 / 歌词 / 资料库 / 系统」分组固定导航，右侧只显示对应内容，点哪项跳哪块
- **搜索页重做**：搜索框独立成页内输入框（带搜索图标和一键清空），最近搜索的「查看全部」在有查询词时收起；在线搜索结果可以一键关闭（状态记忆在本地），关掉后只搜本地曲库，页面上留一个「开启在线搜索」的入口
- **歌单详情吸顶条**：歌单大标题滚出视口后，吸顶返回条才补上歌单名和歌曲数量。判定用元素实际位置而不是写死滚动阈值，长描述的歌单也不会提前或延后显示
- **修复歌单封面不显示**：在线页的歌单卡片原来只读第一首歌的封面，用户自己设过封面的歌单反而显示成空封面。现在优先用歌单自身封面，没有再退回第一首歌
- **修复桌面歌词唱错歌**：切到一首没有歌词的歌（纯音乐 / 歌词还没加载完）时，窗口里会一直挂着上一首的歌词。现在按曲目 id 判断换歌，换歌一律重建（没歌词就显示「暂无歌词」），同一首歌内才保留旧歌词躲开加载中的瞬时空白
- 清理死代码 `renderLocalOnlinePlaylists()`

## 功能

**音乐库**

- 扫描文件夹或选择文件导入，自动识别常见音频格式
- 自动读取标签：标题 / 歌手 / 专辑 / 封面 / 内嵌歌词
- 关闭软件后资料库会保留，下次启动自动恢复（原文件不在原位置时会自动跳过）
- 支持手动刷新：同一文件夹只导入新歌，重复文件按路径去重
- 「只导入歌曲」：自动跳过音效、提示音、语音等非歌曲音频（可按最短时长调整）
- 歌曲详情：格式 / 时长 / 文件大小 / 平均码率 / 采样率 / 声道 / 位深 / 文件位置，可一键定位到文件夹
- 编辑歌曲信息（标题 / 歌手 / 专辑 / 封面，只改资料库不改原文件）
- 查找重复歌曲，一键清理
- 多选 + 全选：批量添加到歌单、批量移除

**播放**

- 播放 / 暂停、上一首 / 下一首、随机、列表循环 / 单曲循环
- 记忆播放进度，再次打开继续上次位置
- 淡入淡出（时长可调）、播放速度 0.5×–2×（保持音高）
- 睡眠定时器：15 / 30 / 45 / 60 / 90 分钟或「播完本曲」
- 音量均衡（ReplayGain）与十段均衡器（31Hz–16kHz，含流行 / 摇滚 / 古典 / 人声 / 低音 / 高音 / 爵士 / 电子预设）
- **耳机校正**：内置 AutoEq 全量 2316 款耳机的校正曲线（头戴 / 入耳），支持按品牌或型号搜索，选中即写入十段增益并套用预增益，可在此基线上继续微调

**歌词**

- 支持歌曲内嵌歌词（MP3 的 USLT / SYLT / TXXX，FLAC、OGG 的 LYRICS 注释，M4A 的 ©lyr）与同名 `.lrc`
- 歌词文件支持 UTF-8 / UTF-16 / GBK 编码，文件名可带 `01.` 之类的序号前缀
- 逐字点亮效果，带轻微漂浮动画
- 右键歌词可按 **0.25 秒** 微调，**按歌曲独立记忆**
- 播放中可以自由上下翻歌词，不会被打断，右下角可一键「回到当前」

![歌词微调](docs/screenshots/歌词微调菜单.png)

**在线音乐**

- 三个音源：网易云音乐 / QQ 音乐 / 酷狗，各自独立登录，登录窗内扫码或快捷登录
- 每日推荐：登录后使用该账号的个性化推荐；未登录时按本地最近播放与收藏的歌手去平台搜索，不向平台暴露个人偏好
- 搜索三家曲库，列表带 VIP / 免费标识、音质与封面，可加入播放队列或自建歌单
- 「我喜欢」：平台红心与本地收藏合并去重；未登录也可用（只存本地）
- 平台歌单 / 榜单可以查看曲目并整张导入成自己的歌单
- **全局搜索**：搜索页输入即出本地结果，同时给出三个平台的在线匹配，可直接播放
- **音质可选**：标准 / 高品质 / 无损，在线页与搜索页共用同一份设置
- 在线收藏、自建歌单与播放历史持久化到本地（`orange-online-lib`）

> QQ 音乐与酷狗的播放权限绑定登录态，未登录时只能拿到试听片段或直接失败；网易云未登录可完整播放免费曲目。

**外观与系统**

- 浅色主题色：默认白 / 蜜桃 / 薄荷 / 天青 / 藕荷 / 柠檬 / 樱花
- 播放浮窗（底部播放条）与左侧功能栏可各自选择 模糊 / 亚克力 / 半透明 / 高斯模糊，并调节模糊与透明程度
- **桌面歌词悬浮窗**：独立置顶的透明歌词窗，Apple Music 风格，支持颜色 / 模糊 / 透明 / 圆角 / 字号 / 对齐自定义，逐字点亮 + 漂浮动画，带悬浮播放控制栏，可拖动与缩放

## 从源码运行 / 构建

环境要求：Node.js 18+（推荐 20+）、Windows 10/11

```bash
# 安装依赖（国内可加 --registry=https://registry.npmmirror.com）
npm install

# 直接运行
npm start

# 打包成安装程序（输出到 release/）
npm run dist

# 打包 + 装到本机 + 导出源码镜像与 zip（交付流程）
npm run publish:github
```

`publish:github` 的落盘位置默认是项目内的 `publish-out/`；要指到别处，在项目根放一个
`publish.local.json`（已在 `.gitignore` 里）：

```json
{
  "mirrorDir": "D:/dist/Orange-Music-${version}-源码",
  "installerDir": "D:/dist/安装包"
}
```

也可以用环境变量 `ORANGE_MIRROR_DIR` / `ORANGE_INSTALLER_DIR` 覆盖。

## 常见问题

**导入后列表是空的？**  
先确认文件是普通音频（MP3 / FLAC / WAV / M4A 等），加密音乐文件无法播放；  
另外「只导入歌曲」会跳过时长过短、没有标签的音效文件，可在设置里关闭。

**歌词显示不出来？**  
点歌曲行的 ⓘ 打开歌曲信息，可以「导入歌词」或「粘贴歌词」；  
也可以把同名的 `.lrc` 放在歌曲旁边，播放时会自动读取。

**歌词对不上时间？**  
在歌词界面点右键，用「歌词提前 / 延后 0.25 秒」微调，只对这首歌生效并自动记住。

**重启后歌曲不见了？**  
资料库记录的是文件路径，如果音乐被移动或删除了就会跳过；重新扫描一次即可。
